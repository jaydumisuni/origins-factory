# AI Workspace Rules

Before creating, downloading, installing, building, testing, caching or cleaning files for this repository, read the canonical policy:

- https://github.com/jaydumisuni/TTG-ecosystem/blob/main/docs/AI_PROJECT_CONTAINMENT_AND_SHARED_TOOLS_POLICY.md
- Recovery mirror: https://drive.google.com/file/d/1oNZ8CeOmjjMOKNuD4ZVN329dvRZucktd/view

Mandatory local rules:

- Declare this repository's project root before writing.
- Keep its source, build, test, cache, temporary files and project-specific tools inside that root or its documented contained locations.
- Do not write into a neighboring repository, drive root, Desktop, Downloads or an arbitrary user/system folder.
- Borrow compatible registered shared builders, SDKs and binaries from the machine's declared shared-tools root.
- Never install a shared builder inside this or another unrelated repository.
- Builder must inventory first, register placement and ownership, verify function and containment, then remove staging, installers and failed-attempt residue.
- Record a reusable lesson in the existing canonical documentation when a non-obvious fix was required.
- Finish with a storage and cleanup report. Unknown files are reported, not deleted.

Repository-specific instructions remain authoritative where they are stricter. Any exception to containment or shared-tool reuse must be explicit and documented.
